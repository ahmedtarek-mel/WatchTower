# Data Directory

This directory is used for storing the CICIDS2017 dataset.

## Dataset Setup

1. Download the CICIDS2017 dataset from:
   https://www.unb.ca/cic/datasets/ids-2017.html

2. Extract and place the CSV files in this directory

3. The main file used is the combined/merged version

## Expected Structure

```
data/
├── README.md
└── CICIDS2017.csv (or similar name)
```

## Note

The dataset file is not included in the repository due to its large size (~440MB).
